1. PROBLEM STATEMENT OVERVIEW
Problem Statement ID: SIH26228 Theme / Domain: Blockchain & Cybersecurity
Sponsoring Org: Ministry of Defence (MoD) Department: Indian Army (DGIS)
Operational Context: Strictly Air-Gapped & Offline Defense Deployment Environment (Zero External Cloud / API
Dependency)
Modern defense and intelligence computer-vision (CV) pipelines routinely source datasets from heterogeneous, distributed
contributors, consume commercial-off-the-shelf or pre-trained models from third-party vendors, and stream real-time
automated inference results to decision-makers. This supply chain introduces massive security vectors: poisoned labels,
backdoor triggers, near-duplicate flooding, out-of-distribution (OOD) blind spots, unauthorized model substitution/
trojanization, and post-inference payload tampering.
The Core SIH Mandate: Build a unified, software-based assurance and inspection layer that inspects the Dataset + AI
Model + Inference Output, binds provenance cryptographically, performs distribution-shift analytics, and generates
actionable, evidence-based governance reports (ACCEPT / REVIEW / QUARANTINE) with complete auditability.

Capability D: Distribution-Shift & Environmental Anomaly
Operational conditions in defense deployments change drastically compared to baseline training domains:
• Sensor & Camera Variations: Sensor noise, focal length changes, optical distortions.
• Environmental Dynamics: Day/Night shifts, heavy rain, fog, dust storms, seasonal terrain alterations.
• Shift Quantification: Utilizes Maximum Mean Discrepancy (MMD) across backbone feature representations and color/
contrast histogram statistics to determine shift severity (LOW, MEDIUM, HIGH).

8. OPERATIONAL VERIFICATION WORKFLOWS
Dataset Analysis Workflow
1. Ingestion & Digest: Calculate SHA-256 checksum upon archive receipt; unpack in sandbox memory.
2. Format Parsing: Automatically detect COCO, YOLO, or standard image directory structure.
3. Integrity Checks: Check file headers, corrupt byte streams, and invalid dimensions.
4. Near-Duplicate Audit: Generate perceptual hashes and compute pairwise Hamming distances to flag duplicate
flooding.
5. Label Discordance: Measure feature-space label consistency to flag label flipping and systematic misannotation.
6. OOD & Poisoning Filters: Screen for out-of-distribution outliers and high-frequency trigger patterns.
7. Contributor Aggregation: Map anomalies to contributor identities to compute contributor-level risk profiles.
Model Analysis Workflow
1. Binary Hash & Parsing: Generate SHA-256 hash; identify framework (ONNX, PyTorch, TorchScript).
2. Static Graph Inspection: Enumerate layers, parameter count, floating-point distributions, and check for anomalies.
3. Reference Battery Evaluation: Execute standardized clean reference samples to establish behavioral baseline.
4. Trigger Search (Neural Cleanse): Optimize for potential backdoor patterns across output classes.
5. Limitation & Confidence Emission: Publish definitive confidence score and coverage limitations.
Inference Provenance & Verification Workflow
1. Operational Execution: Ingest input image, pass through preprocessed pipeline to active model.
2. Canonical Sealing: Bind Input Hash + Model Hash + Config + Prediction + Timestamp + Nonce into
canonical JSON.
3. Hash Generation & Signing: Compute SHA-256 digest and append signature to create protected inference record.

9. RESEARCH BENCHMARKS & EXPERIMENTAL FOUNDATION
The system builds upon proven academic computer-vision datasets and backdoor benchmarks:
• CIFAR-10 Benchmark: 60,000 32×32 color images across 10 classes (50,000 training, 10,000 testing). Serves as the
primary rapid-validation dataset for poison and duplicate simulation.
• GTSRB (German Traffic Sign Recognition Benchmark): Real-world traffic sign classification dataset; standard in
mission-critical vision security and backdoor evaluation.
• MS COCO & YOLO: Large-scale object detection formats utilized to evaluate spatial bounding-box dataset integrity
and multi-object poisoning.
• BackdoorBench Framework: Comprehensive benchmark encompassing 16 backdoor attack methods (BadNets,
Blended, WaNet, BppAttack, TrojanNN, etc.) and 28 defense/detection algorithms across diverse architectures (PreAct-
ResNet18, VGG19, ConvNeXt, ViT).
• TeCo (Temporal/Corruption Consistency): State-of-the-art inference-stage backdoor detection analyzing robustness
consistency under systematic input corruptions.
• BackdoorBenchER: Extended research workflows specifically for CIFAR-10 trigger injection, model poisoning, and
defense validation.
